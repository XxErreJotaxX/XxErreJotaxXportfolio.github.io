## 🛠️ Tech Stack & Features

O projeto foi construído focando em performance e interatividade fluida:

* **HTML5/CSS3:** Estrutura e estilização com efeitos de Glitch e tipografia pixelada.
* **JavaScript (Vanilla):** * **Intersection Observer API:** Utilizada para disparar as animações das barras de "Base Stats" apenas quando o usuário chega na seção, otimizando o processamento.
    * **Drag & Scroll Gallery:** Sistema de navegação por arraste na galeria de artes.
* **Responsive Design:** Totalmente adaptado para dispositivos mobile (testado em Poco X7 Pro).

## ⚔️ Current Quests (Projetos em Destaque)

1.  **PlexSweep:** Script em Python para organização automatizada de arquivos e diretórios.

3.  **Carlucia Melo Eventos:** Sistema web de orçamentos desenvolvido para otimização de processos de negócio.
